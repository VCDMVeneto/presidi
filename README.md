# Portale Presidi Sanitari - V° Centro di Mobilitazione Veneto

Gestione digitale dei presidi sanitari (DAE, fialario, zaino): inventario con QR code, check di pronto uso, sigilli, foto del contenuto, scadenze e avvisi. Riservato al personale del V° Centro di Mobilitazione Veneto della CRI - Corpo Militare.

Indirizzo: https://vcdmveneto.github.io/presidi/

Configurazione: l'indirizzo del backend si imposta in `config.js`.
